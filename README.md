E-Commerce Returns & Operational Analytics


Project Overview
This project focuses on analysing e-commerce returns, order performance, customer purchasing patterns, and operational efficiency using Microsoft Power BI.
The dashboard explores return-related patterns and order characteristics to help understand product returns, identify potential operational issues, and support improvements in customer experience and business performance.

Project Objectives
* Analyse order and return performance.
* Measure the proportion of orders returned.
* Identify products and categories associated with higher return activity.
* Examine customer and order characteristics related to returns.
* Evaluate shipping and operational performance.
* Present actionable insights through an interactive dashboard.

Tools & Technologies
* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Modelling
* Data Visualization

Key Performance Indicators (KPIs)
* Total Orders: Total number of distinct orders.
* Returned Orders: Number of orders identified as returned.
* Total Revenue: Revenue generated from orders, based on the available dataset.
* Total Profit
* Order Return Rate %
* Total Refund Amount

Analysis Performed
* Return Analysis: Evaluated return volumes and return rates.
* Product Analysis: Identified products and categories with higher return activity.
* Customer Analysis: Examined customer purchasing and return patterns.
* Order Status Analysis: Analysed the distribution of orders by status.
* Sales Channel Analysis: Compared order performance across sales channels.
* Payment Method Analysis: Examined order distribution by payment method.
* Shipping Analysis: Evaluated delivery times and shipping performance.
* Geographical Analysis: Compared order and return patterns across countries and regions.
* Order Characteristics Analysis: Explored relationships between order size, order value, and returns.

Data Preparation & Modelling
* Used Power Query to inspect, clean, and transform the data.
* Reviewed data types, missing values, and duplicate records.
* Created DAX measures for key operational and return metrics.
* Developed an appropriate data model for reporting.
* Designed an interactive dashboard for exploring order and return performance.

Key Business Value
* Helps monitor product return activity.
* Highlights product categories and order characteristics associated with returns.
* Supports evaluation of shipping and operational performance.
* Helps businesses identify areas for further investigation.
* Provides insights that can support improvements in customer experience and order management.
